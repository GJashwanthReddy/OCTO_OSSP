Core IPC Concepts

Anonymous Pipe

Unidirectional data channel created in memory using system call pipe(). Shared strictly between parent and child processes created via fork().

Named FIFO

Special file created in the filesystem using mkfifo(). Allows independent, unrelated processes to communicate using standard file system paths.

write() Operation

Transfers raw data bytes from process memory into the kernel IPC buffer. Blocks if the pipe/FIFO buffer is full.

read() Operation

Retrieves data bytes from the IPC buffer into process memory. Blocks if no data is currently available in the buffer.

Note: The browser is visually simulating the execution. In Linux, the real C implementation utilizes system calls as shown below: 

// Anonymous Pipe C Implementation snippet
int fd[2];
pipe(fd); // fd[0] = read end, fd[1] = write end

pid_t pid = fork();

if (pid > 0) { // Process A (Parent / Producer)
    close(fd[0]); // Close read end
    char message[] = "Hello World from Process A";
    write(fd[1], message, strlen(message) + 1);
    close(fd[1]);
} else if (pid == 0) { // Process B (Child / Consumer)
    close(fd[1]); // Close write end
    char buffer[100];
    read(fd[0], buffer, sizeof(buffer));
    printf("Process B Received: %s\n", buffer);
    close(fd[0]);
}

Pipe vs FIFO Comparison

Understanding when to use Anonymous Pipes vs Named FIFOs in Linux Systems Programming.

Feature / Property Anonymous Pipe Named FIFO
Channel Type Anonymous in-memory channel Named special file in filesystem
Process Relationship Strictly related processes (Parent-Child via fork()) Completely independent, unrelated processes
Creation System Call pipe(fd) mkfifo(path, mode)
Filesystem Pathname No filesystem entry / Anonymous descriptor Has a distinct pathname (e.g. linux-implementation/myfifo)
Persistence Exists only while descriptors remain open Persists in filesystem until explicitly removed via unlink()
Opening Mechanism Inherited file descriptors after fork() Opened via standard open() call with O_RDONLY / O_WRONLY

Linux System Call Reference

Key C system calls utilized in Linux Inter-Process Communication.

fork()
Creates a new child process by duplicating the calling parent process context.
Used in Pipe demo to spawn Process B as a child process sharing file descriptors.
pipe(int pipefd[2])
Allocates an anonymous pipe channel; pipefd[0] is read end, pipefd[1] is write end.
Used in Anonymous Pipe demo before fork() to establish communication.
mkfifo(const char *path, mode_t mode)
Creates a FIFO special file at the specified filesystem path with permission mode.
Used in FIFO demo to establish named communication file node.
open(const char *path, int flags)
Opens a file or FIFO node for reading (O_RDONLY) or writing (O_WRONLY).
Used by separate processes to attach to a Named FIFO.
write(int fd, const void *buf, size_t count)
Writes up to count bytes from buffer into the IPC channel file descriptor.
Transmits user payload from Process A into Pipe or FIFO.
read(int fd, void *buf, size_t count)
Reads up to count bytes from the IPC channel into destination buffer memory.
Retrieves payload in Process B from Pipe or FIFO.
close(int fd)
Deallocates a file descriptor so it no longer refers to any file/pipe channel.
Called after transmission to signal End-Of-File (EOF) and free system resources.
unlink(const char *pathname)
Deletes a name from the filesystem; removes FIFO special file node.
Called by FIFO reader or cleanup code after IPC session completes.
